# PharmaCare Pharmacy Order Tracking System

PharmaCare is a web-based Pharmacy Order Tracking System developed to provide a simple and convenient platform for users to browse medicines, place orders and track their orders.

## Project Description

The system allows customers to view available medicines, search for medicines, view product details, add medicines to cart, place orders, view previous orders and track order status.

The system also provides backend APIs for user authentication, medicines, cart, profile, orders and order tracking.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
